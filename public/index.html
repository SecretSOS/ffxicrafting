Why another FFXI site

Wikis document retail, and they drift. A private server runs a specific build of specific code, and that code is public. So this site parses the code.

  • Drop rates come from the server's own loot tables, not from player-reported percentages.
  • Crafting maths (success, HQ tiers, skill-up chance, specialization caps) is read out of the C++ that runs it.
  • Where a server's own settings would change an answer, the site says so instead of guessing.
  • Every number can be traced back to the file it came from.
